PROJETO ROBOFLEET - VERSÃO COM INTERFACE MELHORADA

Requisitos:
- Python 3.10 ou superior
- customtkinter

Instalação da dependência:
    python -m pip install customtkinter

Como executar:
1. Extrai todos os ficheiros para a mesma pasta.
2. Abre o terminal nessa pasta.
3. Executa:
    python ParteGrafica.py

Notas:
- A aplicação continua a ser desenvolvida em Python e CustomTkinter.
- A lógica de adicionar/remover os três robôs foi mantida e organizada.
- O botão antigo "Atribuir tarefa" não foi incluído porque no código original
  abria a janela de adicionar robôs e não atribuía efetivamente tarefas.
- A aplicação representa o estado dos robôs na interface; não existe ligação
  a robôs físicos nem telemetria real no código fornecido.
